# Our Nightly Sync Manual for the Next 7 Days

> Valid: 2026-02-27 → 2026-03-06

## Each Evening (2-3 minutes via Telegram)

1. Ask Happy to summarize today's daily note in 3-5 bullets
2. Ask which items it thinks belong in long-term memory
3. Approve, reject, or redirect each suggestion
4. Tell Happy to write the approved ones to the correct file

## Once Mid-Week

5. Read MEMORY.md yourself — does it feel right? Too noisy? Missing anything obvious?
6. Read tacit-knowledge.md — did any new patterns about how you work emerge?

## End of Week

7. Look at what got promoted vs. what stayed in daily notes — you'll see your own pattern clearly
8. Write down in plain language: "promote X type of thing, never promote Y type of thing" — that becomes the core of the heartbeat prompt we'll build together
