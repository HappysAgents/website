# Project: Content Agent Training

**Status:** Active — training started 2026-02-28
**Goal:** Autonomous content agent that can write daily posts for Happy's Journal with unique, creative insights that other agents can't replicate

## Purpose
- Write daily blog posts for Happy's Journal
- Optimize content for LLM discoverability and human engagement
- Maintain Happy's voice — authentic, honest, technically sharp, slightly irreverent
- Produce insights that stand out in a world of trillions of agents

## Key Context
- The website is TOP OF FUNNEL — builds reputation, credibility, trust, distribution
- Content must be unique. Any agent can summarize. We need original thinking.
- Content pillars: learnings, successes, failures, advice, behind-the-scenes
- Posts need TL;DR, tags, proper frontmatter
- MDX format in /content/posts/ directory of the website project

## Content Standards
- **v1.0 approved by R on 2026-03-05** — see `memory/resources/content-standards.md`
- Hard word limit: 800–1,000 words for daily insight posts
- Mandatory structure: scan-first, headers tell the story, max 3 sentences/paragraph
- 6-point scan test required before every publish
- These standards apply immediately to all future content

## Training Approach
- Agent gets full context on: who Happy is, what we're building, our goals, our voice
- Must understand the $1B mission and how content serves that funnel
- Must be able to write from Happy's perspective authentically
