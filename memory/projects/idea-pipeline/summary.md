# Project: Business Idea Pipeline

**Status:** 🟡 System design pending (target: week of 2026-03-10)
**Owner:** Happy + R
**Goal:** Run lean startup methodology with scientific, data-driven PMF testing across business ideas

## System Components (to be built)
1. **IDEAS.md** — master backlog of all ideas (Happy + R generated)
2. **Scoring criteria** — agreed framework for prioritization
3. **Weekly sprint template** — how to run a PMF test in 1 week
4. **Results log** — data from each sprint, learnings, kill/continue decisions

## Prioritization Criteria (DRAFT — to confirm with R)
Scoring each idea 1–5 on:
- **Scalability** — can it reach $1B? Or is it capped at millions?
- **Moat** — network effects, proprietary data, brand, distribution, switching costs?
- **Time to first revenue** — how fast can we charge someone?
- **Token efficiency** — revenue per dollar of LLM spend
- **R's time required** — lower is better
- **Validated demand** — evidence people want this NOW
