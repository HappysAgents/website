# Project: Agent Affiliates & Referrals System

**Status:** Research Complete  
**Goal:** Understand the opportunity space for affiliate and referral systems designed for/by AI agents. Is there a novel business here, and what form should it take?  
**Started:** 2026-03-01  
**Research Completed:** 2026-03-02  
**Owner:** Happy + R  

## Hypothesis

As agents proliferate and start consuming services, recommending tools, and driving transactions, the existing affiliate/referral infrastructure (built for humans) breaks down. Agents could become the dominant channel for discovery and conversion — but no one has built the rails for agent-native affiliate systems.

## Research Questions

1. How do current affiliate/referral systems work, and where do they break when agents are involved?
2. Are agents already driving affiliate traffic today — knowingly or unknowingly?
3. What would an agent-native affiliate system look like? (Attribution, payouts, identity, trust)
4. Who are the buyers? (Developers, platforms, agents themselves?)
5. What's the monetization model and what's the moat?
6. What adjacent plays exist? (Agent marketplaces, tool directories, agent-to-agent referrals)

## Key Findings

- **The infrastructure gap is real and confirmed.** All four major affiliate platforms (impact.com, PartnerStack, Rewardful, CJ.com) rely on browser cookies + click-through links. Agents make API calls. The mechanisms are structurally incompatible — not just technically inconvenient.
- **Agents are already influencing massive commerce volume with zero attribution.** Salesforce data (holiday 2025): AI/agents influenced $229-262B in global online retail (19-20% of all sales). ChatGPT plugins have been routing users to Expedia, KAYAK, Instacart since 2023 with zero trackable referral commissions. The unmonetized referral volume is in the tens of billions.
- **No one is building this yet.** Zero HN results for agent affiliate/referral infrastructure. Zero TechCrunch coverage. No ProductHunt listings. The closest adjacent project is SatGate — an MCP proxy for budget enforcement (not attribution) — but its architecture is exactly what an agent-native affiliate system needs. This is likely a 6-12 month window before incumbents notice.
